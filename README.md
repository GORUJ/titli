# Titli — The Brother Who Stayed

The website is built. Add your 20 existing illustrations and publish.

## 1. Add images
Copy your images into `assets/images/` named `1.png` through `20.png`. JPG, JPEG, and WebP also work. Keep the number order matching the story.

## 2. Optional music
A custom instrumental background track is included at `assets/audio/music.wav` (about 96 seconds) and loops during playback. The music starts only after the visitor presses the music button.

## 3. Preview
Open `index.html` in a browser. If local image loading is restricted, open the folder in VS Code and use the Live Server extension.

## 4. Publish free
1. Create a GitHub repository named `titli-story`.
2. Upload the contents of this folder (not the ZIP itself).
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then save.
5. Open the published URL shown in the Pages settings.

## Included
- Opening title screen and final letter
- 20 scene-specific captions and emotional narration
- Image slideshow with auto-play, pause, next/previous, progress, scene dots, keyboard controls
- Responsive desktop/mobile layout
- Optional background music
- Fallback message if an image is missing

## Edit the words
Open `script.js`; the `scenes` array contains the title, caption, explanatory paragraph, and Ayush's voice-over for every image.

Privacy note: public GitHub Pages content can be seen by others. Keep private chats and sensitive personal details out of the public site. The story expresses Ayush's feelings without suggesting Prachi owes him for his care.
